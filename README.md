# APB4-Based-SPI-Master-Controller---RTL-Design-and-Verification
APB4-based SPI Master Controller designed using Verilog RTL and verified using SystemVerilog/UVM, supporting all four SPI modes (CPOL/CPHA 00, 01, 10, 11) with APB register transactions, SPI data transfer, functional coverage, and clock-domain synchronization.
